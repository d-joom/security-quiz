(답) named.conf, resolv.conf

* 리눅스 DNS 설정 파일 문제다. resolv.conf를 resolve.conf로 잘못 쓰지 않도록 철자에 주의해야 한다.
* /etc/named.conf: BIND 기본 설정 파일(zone 설정, recursion·allow-transfer 등 보안 옵션). /etc/resolv.conf: 시스템 기본 네임서버 설정. /etc/hosts: 도메인/호스트명과 IP 매핑.
* DNS 우선순위(Linux): nscd(설치된 경우) /etc/hosts > /etc/resolvconf/resolv.conf.d > /etc/resolv.conf > 내부 DNS > 외부 DNS. (Windows): DNS 캐시 > hosts.ics > hosts > 내부 DNS > 외부 DNS.
* DNS 포트: 53/udp는 응답이 512바이트 이하일 때, 53/tcp는 512바이트 초과(또는 존 전송)일 때 사용한다.
* DNS 서버 보안: named.conf에서 recursion no 또는 allow-recursion으로 재귀 질의를 제한하고, allow-transfer로 존 전송을 Slave DNS 주소로만 제한한다.

15. 다음 DoS 공격의 원리를 각각 서술하시오.

(a) Land Attack
(b) Smurf
(c) Teardrop

(답)
(a) Land Attack : 출발지 IP와 목적지 IP를 같은 주소(공격 대상의 주소)로 만들어 전송하여, 수신자가 자기 자신에게 응답을 보내게 함으로써 시스템의 가용성을 침해하는 공격 기법이다.
(b) Smurf : 출발지 IP 주소를 공격 대상의 IP로 위조하여 네트워크 전체에 ICMP Echo 패킷을 브로드캐스트하고, 응답이 공격 대상에 집중되어 목표 시스템을 마비시키는 공격 기법이다.
(c) Teardrop : IP 패킷 재조합 과정에서 잘못된 Fragment Offset 정보를 이용해 단편이 겹치거나 어긋나게 하여, 수신 시스템에 오류(크래시)가 발생하도록 만드는 DoS 공격이다.

* 교재의 DoS 공격 비교 표를 외워 두어야 한다. Teardrop은 Fragment Offset 키워드가 핵심이다.
* 핵심 키워드는 출발지=목적지 IP, ICMP Echo 브로드캐스트, Fragment Offset

(1) SUID 설정 시 일반 사용자가 해당 파일을 실행하면 파일 소유자의 권한을 획득할 수 있어 root 권한 탈취 등이 가능하다.
(2) SGID 설정 시 일반 사용자가 해당 파일을 실행하면 파일 소유 그룹의 권한으로 명령을 실행할 수 있어 권한 상승이 가능하다.
(3) chmod -s <file_name>
(4) 4000 (04000)
(5) 2000 (02000)

* find / -perm -4000 -type f 로 SUID, find / -perm -2000 -type f 로 SGID 파일을 찾는다. 불필요한 SUID/SGID 파일은 chmod -s 로 제거한다.
